# 哲学的来源

AgentOrganon 使用 Core 哲学作为自身维护基准。工作区评估使用你显式选择的已采纳哲学，不能自动用捆绑的 Core 替代。

- [阅读 Core 哲学](https://shendeguize.github.io/OrganonCore/zh/philosophy)
- [选择领域哲学](https://shendeguize.github.io/AdvisedOrganons/zh/philosophy)
- [理解基准、提议和方法约束](understand.md)

根目录 `PHILOSOPHY.md` 是只读源链接；工作区采纳使用独立的普通文件。安装更新不自动改变已采纳哲学。
